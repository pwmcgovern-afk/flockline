These are the fields prepared in the request form. Flockline is the project name; no for-profit affiliation has been asserted. The description asks Cornell to confirm the General classification and any additional permission required for a future commercial use.

## Project description

I develop Flockline (https://flockline.app), a free public birding website and email digest. I request eBird Basic Dataset and Sampling Event Data access to calculate species-by-county seasonal reporting frequencies, complete-checklist denominators, and year-by-year recurrence for the United States, starting with a small regional pilot and 2016–2025 observations. These compact derived summaries would appear beside current reports with sample sizes, baseline years, geographic scope, citations, and limitations. They would describe reporting frequency, not population size or an official rarity classification. Original downloads and checklist-level records would remain private; preprocessing would be offline. Please confirm whether public display of summaries derived from official histogram downloads and EBD is covered for this use, whether General is the appropriate project classification, and what additional permission would be required if future sponsorship or another commercial model is introduced. I would provide Cornell a link to the resulting product and follow applicable attribution and sensitive-species requirements.

## What the published guidance establishes

Cornell's [Data Access Terms of Use](https://www.birds.cornell.edu/home/ebird-data-access-terms-of-use/) allow derived datasets to be passed on under the same terms, require attribution and the declared purpose, and prohibit redistribution of original datasets. Commercial use requires prior written permission. The definition includes use by, for, or assisting a for-profit entity, so a free website is not automatically noncommercial. These terms do not state a blanket ban on displaying derived statistics publicly.

The [official download guide](https://support.ebird.org/en/support/solutions/articles/48000838205-download-ebird-data) identifies histogram downloads as a supported source and describes EBD project requests as typically approved within seven days. Its [data-use guidance](https://support.ebird.org/en/support/solutions/articles/48001078113) allows cited eBird web visualizations subject to the applicable terms. The request documents the intended public educational use and asks about future sponsorship. It does not presume that hypothetical future commercial activity makes the current project commercial.

The user has authorized a free public educational pilot. Publish its derived summaries with attribution, source links, baseline metadata, and the applicable data terms. Keep original downloads outside the repository. There is no additional publication hold inferred from the terms for this current noncommercial use. A future commercial use still requires prior written permission.

## Coverage plan

For a bounded pilot, download full-year, ten-year histograms through eBird's supported action for a few well-sampled counties and relevant hotspots. The [bar-chart documentation](https://support.ebird.org/en/support/solutions/articles/48001255130-ebird-bar-charts-and-graphs) supports changing location and date range from region and hotspot pages. Add geography only when its export has been obtained and checked. A missing county must remain unavailable or use an explicitly named broader area, never silently inherit a nearby county's values.

Pooled exports support seasonal frequency and sample size, but not annual recurrence. Separate annual exports can test recurrence for a small pilot. Nationwide county coverage, consistent effort filtering, and routine refreshes should use approved EBD plus Sampling Event Data processing rather than a growing set of manual exports or automated scraping. Start with regional subsets after access is approved; there is no need to download the entire global EBD to prove the feature.

This request concerns the EBD and official histogram exports. It does not request or assume permission for redistribution of eBird Status and Trends underlying model products, which have separate terms.
